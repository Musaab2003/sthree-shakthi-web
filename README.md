# ?? Project Sthree Shakthi | Digital Platform

> **An initiative by Rotaract District 3220 Cluster 05 empowering women across Sri Lanka through confidence, capability, and digital community publishing.**

---

## ? Overview

**Project Sthree Shakthi** is a community-driven web platform designed to amplify the voices and achievements of women across Sri Lanka. It serves as a central hub for women's empowerment initiatives, community storytelling, and digital publication publishing across Rotary & Rotaract Cluster 05 clubs.

Developed by **Transformative Matrix Technologies**.

---

## ?? Key Features

- **?? View-Only Digital Publishing Hub**:
  - In-browser interactive reader for community PDF magazines, Word articles, and research reports.
  - Dynamic editorial cover generator for uploaded documents.
  - Safe, copyright-protected view-only reading mode.

- **?? Newsletter & Community Broadcast Suite**:
  - Direct subscriber collection and real-time database management.
  - 1-click privacy-protected BCC broadcast dispatcher.
  - CSV subscriber export and dispatch audit log.

- **?? Secure Admin Portal**:
  - Full-screen moderation dashboard with SHA-256 cryptographic hashing.
  - 1-click submission approval, rejection feedback, and homepage spotlight toggling.
  - Live editorial metrics and subscriber counts.

- **?? Cluster 05 Clubs Directory**:
  - Interactive showcase of participating Rotaract clubs and leadership pathways.

---

## ??? Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons
- **Database / Backend Integration**: Turso Cloud (libSQL), IndexedDB
- **Security**: SHA-256 Web Crypto API
- **Deployment**: Vercel
